# ExpenseFlow — Personal Finance Tracker

A modern, full-stack personal finance management application built using React, Django REST Framework, and PostgreSQL.

🌐 **Live Demo:** https://expenseflow-app-kohl.vercel.app

## Features

- Secure user registration and login
- JWT authentication using HttpOnly cookies
- CSRF protection and automatic token refresh
- Income and expense tracking
- Transaction management (Add, Edit, Delete)
- Custom categories and budget management
- Interactive dashboard and financial analytics
- Responsive user interface

## Tech Stack

**Frontend**
- React.js (Vite)
- Redux Toolkit
- Axios
- Recharts

**Backend**
- Python
- Django
- Django REST Framework
- JWT Authentication

**Database**
- PostgreSQL (Supabase)

**Deployment**
- Vercel
